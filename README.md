### Core Areas

- **Telegram-first products** — bots, Telegram Web Apps, subscriptions, support flows, admin panels, analytics, and broadcasts.
- **AI automation** — structured LLM pipelines, RAG/context flows, draft generation, scoring systems, and human-in-the-loop tools.
- **SaaS and internal tools** — Next.js frontends, Python/FastAPI services, dashboards, payments, integrations, and operator workflows.
- **VPN/proxy infrastructure** — panel integrations, node APIs, subscription/traffic logic, Mihomo/Clash routing, and desktop client tooling.

### Product Mindset

Most of my work sits between product ownership and implementation. In my own VPN product, **BPN / BadVPN**, I work across the full product loop:

- roadmap, pricing, subscriptions, retention, support, and payment reliability;
- Telegram bot, Telegram Web App/PWA, public site, admin/support tools, and backend automation;
- analytics, AI-assisted support workflows, billing/referral logic, and user lifecycle edge cases;
- Windows desktop client work around Tauri, Rust, Mihomo, Smart Routing, and zapret/winws flows.

That background is useful for freelance and contract work where the goal is not only to ship code, but to make the workflow reliable for users, operators, and the business.

### How I Work

- I prefer small, reviewable changes over broad rewrites.
- I design around failure modes: retries, fallback paths, redacted logs, diagnostics, and operator visibility.
- I care about the business workflow behind the code: pricing, support, payments, retention, and handover.
- I use AI tools aggressively, but keep human responsibility for architecture, review, security, and product judgment.
